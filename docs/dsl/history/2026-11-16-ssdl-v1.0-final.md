# SSDL 最终定稿：调度与子目标描述语言

> **历史文档（已撤销）**：自 2026-11-18 起，v1 不再是表面语法。
> 本文描述的 EBNF 现仅作为 IR 文本格式（`elaborate.render` 的输出）存在，
> 唯一表面文法见 `../2026-11-17-ssdl-v2-grammar.md`，
> 决定记录见 `../2026-11-18-ssdl-one-surface.md`。


**名称**：SSDL — Scheduling and Subtarget Description Language
**中文**：调度与子目标描述语言
**版本**：1.0 Final
**定位**：LLVM 后端中，描述"指令在微架构上如何被调度、识别、绑定"的领域专用声明语言。不描述指令本身，只描述指令与微架构之间的运行时契约。

---

## 一、设计原则（定稿）

1. **9 个平级顶层关键字**：`set` / `predicate` / `predicate_prolog` / `feature` / `sti_decl` / `sti_function` / `tii_predicate` / `machine` / `itineraries`。
2. **无 base / 扩展概念**：用户不需要理解"扩展"，特化通过 `kind` 属性和可选字段承载。
3. **无元编程**：不支持 `foreach`，不支持 `constructor`。展开后的显式声明是 SSDL 的核心价值。
4. **语法融合，语义分层**：用户看到一层平级语法；宿主展开时按领域模型分层（语义层/策略层/ABI 层）。
5. **n 元组合子**：`all_of` / `any_of` 是 n 元，保留空参数语义，不引入二元中缀。
6. **列表语法统一**：一套 `[...]` 走天下，支持空列表、尾随逗号、展开 `...`、范围 `[a..b]`。
7. **属性抽象分层**：`set` 声明具名集合，谓词只引用名字。

---

## 二、词法层

```ebnf
IDENT       = letter { letter | digit | "_" } ;
INT         = digit { digit } ;
STRING      = '"' { any_char | escape } '"' ;
BOOL        = "true" | "false" ;
CODE_BLOCK  = "[{" { any_char } "}]" ;
COMMENT     = "#"  { any_char } newline
            | "//" { any_char } newline
            | "/*" { any_char } "*/" ;
```

## 三、完整 EBNF

### 3.1 程序与顶层声明

```ebnf
program
    = { top_decl }
    ;

top_decl
    = set_decl
    | predicate_decl
    | predicate_prolog_decl
    | feature_decl
    | sti_decl
    | sti_function
    | tii_predicate
    | machine_decl
    | itineraries_decl
    ;
```

**9 个顶层关键字，平级，无扩展关系。**

---

### 3.2 `set` 声明（全局具名集合）

```ebnf
set_decl
    = "set" IDENT "=" set_expr ";"
    ;

set_expr
    = "inst" "(" attr_cond ")"
    | "reg"  "(" attr_cond ")"
    | "[" [ set_item { "," set_item } [ "," ] ] "]"
    ;

set_item
    = "..." IDENT
    | "..." set_expr
    | inst_ref
    | reg_ref
    ;
```

---

### 3.3 `predicate` 声明（两种形态）

```ebnf
predicate_decl
    = "predicate" IDENT "=" predicate_expr ";"
    | "predicate" IDENT "{"
        "selector"  "=" cxx_expr     ";"
      [ "assembler" "=" feature_expr ";" ]
      [ "desc"      "=" STRING       ";" ]
      [ "recompute_per_function" "=" BOOL ";" ]
      "}"
    ;
```

**形态 1**：纯调度谓词（单行表达式），对应 TD 的 `MCInstPredicate`。
**形态 2**：指令选择/汇编匹配谓词（块形式），对应 TD 的 `Predicate` + `AssemblerPredicate` 双继承。

---

### 3.4 `predicate_prolog` 声明

```ebnf
predicate_prolog_decl
    = "predicate_prolog" "(" CODE_BLOCK ")" ";"
    ;
```

---

### 3.5 `feature` 声明（统一，`kind` 区分形态）

```ebnf
feature_decl
    = "feature" IDENT ":"
      { feature_field }
      ";"
    ;

feature_field
    (* 通用属性 *)
    = "kind"             "=" feature_kind
    | "desc"             "=" STRING
    | "implies"          "=" ident_list

    (* plain / extension / tune 共有 *)
    | "field"            "=" STRING
    | "value"            "=" STRING
    | "inline_behavior"  "=" inline_behavior

    (* extension 独有 *)
    | "version"          "=" STRING
    | "experimental"     "=" BOOL
    | "bitmask"          "=" bitmask

    (* tune 独有 *)
    | "positive_directive"  "=" STRING
    | "negative_directive"  "=" STRING
    ;

feature_kind
    = "plain" | "extension" | "tune"
    ;

inline_behavior
    = "ignore" | "default" | "inverse" | "must_match"
    ;

bitmask
    = "{" "group" "=" INT "," "bit" "=" INT "}"
    ;
```

**`kind` 默认值**：未写 `kind` 时视为 `plain`。

**属性合法性检查**：

| `kind` | 必须写 | 支持写 | 不可写 |
|---|---|---|---|
| `plain` | `field`、`value` | `desc`、`implies`、`inline_behavior` | `version`、`experimental`、`bitmask`、`*_directive` |
| `extension` | `version` | `field`、`value`、`desc`、`implies`、`experimental`、`bitmask` | `*_directive` |
| `tune` | `field`、`value` | `desc`、`implies`、`*_directive` | `version`、`experimental`、`bitmask` |

### 3.6 谓词表达式

```ebnf
predicate_expr
    = "true" | "false"
    | "not" "(" predicate_expr ")"
    | "all_of" "(" [ predicate_expr { "," predicate_expr } [ "," ] ] ")"
    | "any_of" "(" [ predicate_expr { "," predicate_expr } [ "," ] ] ")"
    | "feature" "(" IDENT ")"
    | atom_pred
    ;

atom_pred
    = opcode_pred
    | operand_pred
    | count_pred
    | same_reg_pred
    | func_pred
    | non_portable_pred
    ;

opcode_pred
    = "opcode" "(" ( IDENT | set_expr ) ")"
    | "pseudo" "(" ( IDENT | set_expr ) ")"
    ;

operand_pred
    = "is_reg"          "(" INT ")"
    | "is_vreg"         "(" INT ")"
    | "is_not_vreg"     "(" INT ")"
    | "is_imm"          "(" INT ")"
    | "is_valid_reg"    "(" INT ")"
    | "is_invalid_reg"  "(" INT ")"
    | "is_zero"         "(" INT ")"
    | "reg_is"          "(" INT "," ( IDENT | reg_ref | set_expr ) [ "," mapper_arg ] ")"
    | "imm_is"          "(" INT "," INT [ "," mapper_arg ] ")"
    | "imm_is_enum"     "(" INT "," STRING [ "," mapper_arg ] ")"
    | "imm_lt"          "(" INT "," INT [ "," mapper_arg ] ")"
    | "imm_gt"          "(" INT "," INT [ "," mapper_arg ] ")"
    | "imm_le"          "(" INT "," INT [ "," mapper_arg ] ")"
    | "imm_ge"          "(" INT "," INT [ "," mapper_arg ] ")"
    | "imm_range"       "(" INT "," INT "," INT [ "," mapper_arg ] ")"
    | "reg_simple"      "(" INT [ "," mapper_arg ] ")"
    | "imm_simple"      "(" INT [ "," mapper_arg ] ")"
    ;

count_pred       = "num_ops" "(" INT ")" ;
same_reg_pred    = "same_reg" "(" INT "," INT ")" ;

func_pred
    = "func"      "(" STRING "," STRING ")"
    | "func_tii"  "(" STRING "," STRING [ "," tii_arg ] ")"
    ;

non_portable_pred = "non_portable" "(" CODE_BLOCK ")" ;
mapper_arg        = "map" "=" IDENT ;
tii_arg           = "tii" "=" STRING ;
```

### 3.11 `machine` 声明（统一，两种形式）

```ebnf
machine_decl
    = "machine" IDENT "{" { machine_item } "}"
    | "machine" IDENT "=" IDENT ";"
    ;

machine_item
    = machine_prop
    | entity_decl
    | relation_decl
    | itineraries_decl
    ;

machine_prop
    = "features"                    "=" ident_list ";"
    | "tune_features"               "=" ident_list ";"
    | "default_march"               "=" STRING     ";"
    | "issue_width"                 "=" INT        ";"
    | "micro_op_buffer_size"        "=" INT        ";"
    | "loop_micro_op_buffer"        "=" INT        ";"
    | "load_latency"                "=" INT        ";"
    | "high_latency"                "=" INT        ";"
    | "mispredict_penalty"          "=" INT        ";"
    | "post_ra_scheduler"           "=" BOOL       ";"
    | "complete_model"              "=" BOOL       ";"
    | "full_inst_rw_overlap_check"  "=" BOOL       ";"
    | "enable_intervals"            "=" BOOL       ";"
```

### 3.16 属性表达式（编译期）

## 四、展开规则（`norm`）

以下规则在语义分析阶段应用，用户不需要知道，但宿主必须实现。

### 4.1 谓词层展开

```text
is_valid_reg(i)         → not(is_invalid_reg(i))
is_not_vreg(i)          → not(is_vreg(i))
is_zero(i)              → imm_is(i, 0)
pseudo(insts)           → opcode(insts)        [非 MC 层]
reg_simple(i) 无 map    → is_valid_reg(i)
imm_simple(i) 无 map    → true
opcode(SetName)         → opcode([显式指令列表])
reg_is(i, SetName)      → reg_is(i, [显式寄存器列表])
inst(attr_cond)         → [满足条件的指令列表]
reg(attr_cond)          → [满足条件的寄存器列表]
[...A, B, ...C]         → A元素 ++ [B] ++ C元素
[a..b]                  → [a, a+1, ..., b]
```

### 4.2 机器层展开

```text
machine X { ... }       → 所有块内实体/关系绑定 SchedModel = X
machine X = Y;          → X 引用 Y 的所有属性
bind W -> [R];          → WriteRes<W, [R]> { Latency=1; NumMicroOps=1; ... }
map [...] -> [...];     → InstRW<[...], (instrs ...)>
variant W { ... }       → SchedWriteVariant<[SchedVar<...>]>
```

### 4.3 `feature` 按 kind 分层展开

```text
feature X : kind = plain, field = "...", value = "...";
  → emit_subtarget_feature(X)   → SubtargetFeatureKV

feature X : kind = extension, version = "...", bitmask = {...};
  → 语义层：emit_subtarget_feature(X)          → SubtargetFeatureKV
  → 策略层：emit_isa_info_policy(X)            → RISCVISAInfo 解析表
  → ABI 层：emit_runtime_probe(X)              → __riscv_feature_bits

feature X : kind = tune, positive_directive = "...", ...;
  → emit_subtarget_feature(X)   → SubtargetFeatureKV + 命令行指令名映射
```

### 4.4 `predicate` 按形态展开

```text
predicate P = expr;
  → Predicate<展开后的 C++ 表达式>            [调度用]

predicate P { selector = ...; assembler = ...; }
  → Predicate<selector C++ 代码>              [指令选择]
  → AssemblerPredicate<assembler DAG>         [汇编匹配]
```

### 4.5 `machine` 的 `default_march` 展开

```text
machine X { default_march = "rv64i2p1"; ... }
  → 生成 RISCVProcessorModel 的 default_march 字段
  → 影响 -mcpu=X 且未指定 -march 时的默认架构
```

## 五、完整例子：RISC-V SiFive7 微架构

```text
# ============ 具名集合 ============
set ZeroRegs     = reg(is_zero_reg);
set LogicalInsts = [ORR, EOR, AND, ...inst(category == logical),];

# ============ 谓词 ============
predicate IsZeroReg(i) = reg_is(i, ZeroRegs);

predicate HasStdExtI {
    selector  = cxx_expr([{ Subtarget->hasStdExtI() }]);
    assembler = all_of([StdExtI]);
    desc      = "'I' (Base Integer Instruction Set)";
}

predicate NoStdExtZbb {
    selector  = cxx_expr([{ !Subtarget->hasStdExtZbb() }]);
    assembler = none_of([StdExtZbb]);
}

predicate_prolog([{
    auto *RI = MI->getParent()->getParent()->getSubtarget().getRegisterInfo();
}]);

# ============ Feature ============
feature StdExtI :
    kind = extension,
    version = "2.1",
    bitmask = { group = 0, bit = 8 },
    desc = "Base Integer Instruction Set";

feature StdExtZicntr :
    kind = extension,
    version = "2.0",
    implies = [StdExtZicsr],
    bitmask = { group = 1, bit = 15 },
    desc = "Base Counters and Timers";

feature StdExtZibi :
    kind = extension,
    version = "0.1",
    experimental = true,
    bitmask = { group = 1, bit = 13 },
    desc = "Branch with Immediate";

feature Feature64Bit :
    kind = plain,
    field = "IsRV64", value = "true",
    desc = "Implements RV64";

feature TunePostRA :
    kind = tune,
    positive_directive = "use-postra-scheduler",
    negative_directive = "no-use-postra-scheduler",
    field = "UsePostRAScheduler", value = "true",
    desc = "Schedule again after register allocation";

# ============ STI 声明 ============
sti_decl isZeroIdiom {
    opcode_mask = true;
}

sti_decl isDependencyBreaking {
    opcode_mask = true;
    delegates   = [isZeroIdiom];
}

# ============ 机器模型 ============
machine generic-rv64 {
    features      = [Feature64Bit, StdExtI, StdExtZifencei, StdExtZicsr];
    default_march = "rv64i2p1_zicsr2p0_zifencei2p0";
}

machine siFive7 {
    features             = [Feature64Bit, StdExtI, StdExtM, StdExtA, StdExtF, StdExtD, StdExtC];
    tune_features        = [TuneSiFive7, TuneNoDefaultUnroll];
    issue_width          = 4;
    micro_op_buffer_size = 192;
    load_latency         = 3;
    mispredict_penalty   = 9;
    complete_model       = false;

    resource PipeA : units = 2;
    resource PipeB : units = 2;
    resource LSU   : units = 1, buffer = 4;

    write W_ALU; write W_LD;
    read  R_ALU;

    bind W_ALU -> [PipeA], latency = 1;
    bind W_LD  -> [LSU],   latency = 3, release = [3];

    advance R_ALU : cycles = 1 : writes = [W_ALU];

    map [ADD, SUB, AND] -> [W_ALU, read_default, read_default];
    map [LD]            -> [W_LD,  read_default];
    map [ORR]           -> [W_ALU, read_default, read_default];

    variant W_ALU {
        case all_of(opcode([ORR]), IsZeroReg(1), IsZeroReg(2)): [W_ALU];
        default: [W_ALU];
    }

    reg_file GPRFile {
        num_phys             = 180;
        classes              = [GPR64, GPR32];
        allow_move_elim      = [true, true];
        max_move_elim_per_cy = 4;
    }

    retire_unit { buffer = 320; max_per_cycle = 6; }
    load_queue  : resource = LSU;
    store_queue : resource = LSU;

    itineraries : packetizer_namespace = "SiFive7" {
        func_units = [FU_ALU, FU_LSU];
        bypasses   = [no_bypass];
```

## 七、九条定稿声明

1. **9 个顶层关键字**：`set` / `predicate` / `predicate_prolog` / `feature` / `sti_decl` / `sti_function` / `tii_predicate` / `machine` / `itineraries`。
2. **`feature` 用 `kind` 区分形态**：`plain` / `extension` / `tune`，用户不需要理解"扩展"概念。
3. **`predicate` 用可选字段区分用途**：表达式形式用于调度，块形式用于指令选择/汇编匹配。
4. **`machine` 统一，`default_march` 可选**：x86/ARM 不写，RISC-V 写；别名用 `machine X = Y;`。
5. **无元编程**：不支持 `foreach`，不支持 `constructor`。展开由外部生成器或宿主完成。
6. **语法融合，语义分层**：`feature kind = extension` 展开时分语义层/策略层/ABI 层三路 `emit`。
7. **n 元组合子**：`all_of` / `any_of` 保留空参数语义，不引入二元中缀。
8. **列表语法统一**：一套 `[...]` 走天下，支持空列表、尾随逗号、展开、范围。
9. **属性抽象分层**：`set` 声明具名集合，谓词只引用名字。
